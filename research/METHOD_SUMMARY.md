# Method summary and the record of everything tried since 2026-11-13

2026-11-21, Asia/Taipei. For teammates and the paper. **Development evidence only (synthetic fixtures, four small models); no held-out result, no causal claim.** Numbers are copied from the linked reports (reported evidence, not independently rerun here); anything without a report in this checkout is marked "record missing". Source list: owner-approved update list of 2026-11-21 (`Claude outputs/2026-11-21_CC_CONTEXT_UPDATE2_AND_PUBLISH.md`).

## 1. The final method M (idea freeze, 2026-11-21)
| component | what it does | dev evidence | status |
|---|---|---|---|
| Short tool menu | Offers 12 ROS/log read tools plus the finish tool instead of the 47 stock tools; write tools stay blocked | Ablation (40 cells): supported 36 with it, 30 without; tokens 776,614 against 1,981,947 (x2.55; 35 more schemas add 2,029-3,666 tokens to every request). [Ablation report](studies/steady_loop_ablation_20261117/REPORT.md) | core |
| Structured finish tool | `final_answer` takes a non-empty JSON object and ends the episode | Ablation: 36 with, 29 without, in the same direction in all four models, mechanism not established; finish split: tool only 69 = full 69 of 80, line-JSON variant 62 ([report](studies/finish_split_20261118/REPORT.md)) | core |
| Errors as text (soft errors, including the strict argument pre-check) | A failed call is returned to the model as a tool message, with field, expected type and received value | Ablation: minus soft errors 34, minus pre-check 37 of 40 (not shown to matter on these cells; returned errors were rare). Fairness test: errors-as-text alone (stock tools and executor, better prompt) 65 of 80 against the fixed loop's 67, so most of the gain over the stock executor is this part ([report](studies/fairness_errors_as_text_20261117/REPORT.md)) | core (one component) |
| Answer name fix | Name-rewrite v2 on the submitted final answer: a short name becomes the one earlier-seen full name it uniquely matches; no extra request | Applied test 54 -> 62 of 64 (8 answers changed, all strict-unsupported -> supported, 0 harmful); fresh-seed replay 243 -> 252 of 288, 0 harm; 1,832 saved episodes 0 down, 19 up. 7 of 9 fresh-seed gains in designed name-fix tasks. [Report](studies/name_fix_applied_20261117/REPORT.md); owner adoption 2026-11-20 | minor supporting; raw answer is scored as well, rewritten answers are their own group |
Not in M: argument coercion (the 2026-11-19 conversion exists only as an offline count) and the `""` fix (owner decision 2026-11-21: reported as an interface issue equal for all arms).

## 4. Paper pattern (a summary line from the owner-approved list; a hypothesis-level reading of the table above, not a tested claim)
Structure the model cannot ignore helps (short menu, structured finish, errors returned as text); advice, nudges and extra thinking do not; reactive rules harm runs that would have recovered; the remaining waste is mostly untriggered weak-model randomness (derailment study: the largest trigger group is "none").
