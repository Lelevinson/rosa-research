The bounded offline implementation adds STOP to grouped history, compares status/
registry/output-shape conditioning, preserves ambiguous origin paths and rejects
uncertified continuation. These are experimental changes to the interface and
admission discipline, not a claimed new algorithm. Ordinary conditional backoff
with the identical binder and gates reproduces the final candidate exactly.

PASTE's inspected version already conditions patterns on outcomes and maps current
payload arguments, while confirming against authoritative model generation. AWM
includes parameterized callable workflows, so macro competition is substantive.
SpecAgent charges draft/review and treats final submission as consequential.
AutoTool already has recognized-error fallback, support weighting, context and
parameter dependencies. None is fairly represented by an error-blind predictor.

The offline parent arm is explicitly CONSTRAINED: it reproduces first contiguous
recent-k matching, frequency/support factor and strict threshold, but uses grouped
decision symbols and an added STOP label; alpha=1 removes the unavailable SimCSE
term; the common conservative binder replaces domain adapters. Full AgentBoard,
parent rate caps/recovery, model/embedding preprocessing and semantic fillers
were not executed. No faithful reproduction, parent-paper performance comparison
or superiority over full AutoTool is claimed. Actual cost of unavailable components
is UNKNOWN rather than zero. Only the constrained program's measured work is charged.

Wilson lower bounds are ordinary development diagnostics. Correlated trajectories,
tiny cell support, unseen registry state and unlabeled action necessity prevent a
calibrated task-risk claim. Tool-call behavior is not a substitute for necessity
labels, even with a mathematically valid binomial calculation.
