# Dev check of `analyze_primary.py` (public development results only)

Input: `dev_rows_full_vs_e1_seed1.jsonl` = the 40 `FULL` rows of the steady-loop ablation (2026-11-17, phase full, seed 1; the method loop without the name fix) and the 40 `E1` rows of the fairness test (2026-11-17, phase full, seed 1), copied field by field from their `RESULTS_LOG.jsonl` files (aggregate fields only). The two arms were run in different sessions on the same 10 development tasks x 4 models.
Command: `analyze_primary.py --rows dev_rows_full_vs_e1_seed1.jsonl --system-field arm --primary FULL --baseline E1 --planned-pairs 40 --out dev_full_vs_e1_seed1`. Output: `dev_full_vs_e1_seed1.md` and `.json`.
**What this shows:** the script runs end to end on real rows and its counts equal an independent recount (unit test `PublicDevelopmentResultsTest`). **What it does not show:** nothing about the held-out exam. The "PASS" printed here is an exercise of the rule on 40 cells and 10 tasks from two different sessions: the interval is illustrative (the draft's own power note says 10 tasks cannot support a claim), the name-fix-both-ways section is empty because these dev rows have no `supported_raw`, and the pass/fail rule was written for 76 tasks x 4 models x 3 seeds.
